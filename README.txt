FastAPI & SQLAlchemy Web Application

A full-stack web app built with FastAPI, SQLAlchemy, and PostgreSQL, featuring a Jinja2 frontend, an admin panel, and an integrated caching system.

Tech Stack

    Backend: Python, FastAPI, SQLAlchemy

    Database: PostgreSQL

    Frontend: HTML5, CSS3, Jinja2

Quick Start

    Clone the repo: git clone <repo-url>

    Create & activate venv: python -m venv venv && source venv/bin/activate (Windows: venv\Scripts\activate)

    Install dependencies: pip install -r requirements.txt

    Set up .env with your DATABASE_URL and SECRET_KEY.

    Run the app: uvicorn main:app --reload
